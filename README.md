## How to Review a Pull Request Diff

1. Open the Pull Request on GitHub.
2. Open the "Files changed" tab.
3. Review the modified files.
4. Lines beginning with `-` show removed or previous content.
5. Lines beginning with `+` show added or new content.
6. Check that the changes match the purpose of the Pull Request.
7. Check that there are no unrelated changes.
8. Confirm that the Pull Request is targeting the correct branch.
